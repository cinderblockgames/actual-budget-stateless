This project adheres to the [SciActive Human Contribution Policy 2-NE](HUMAN-CONTRIBUTION-POLICY-2-NE.md).

To contribute:
1. Fork the `develop` branch of this repository.
2. Add a `Properties/launchSettings.json` file with your `environmentVariables`.
3. Make your changes.
4. Open a pull request with a description of what's been changed.
