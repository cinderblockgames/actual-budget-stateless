# Actual Budget Stateless
This project wraps [jhonderson's actual-budget-api](https://github.com/jhonderson/actual-http-api) to provide a view of an Actual Budget instance without the need for clients to maintain state (as state is maintained by the API).  This results in quick page loads and no need to wait for clients to sync up data.

The initial goal of this project is to provide readonly access to the data, with potential for update support in future releases.
